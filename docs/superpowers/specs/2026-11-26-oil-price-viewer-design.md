# 油价看板（GitHub Pages）设计方案

- 日期：2026-11-26
- 版本：v2（已并入 builder-check 复核结论，见 §15）
- 状态：待评审
- 仓库：`oil-price-viewer`（GitHub Pages 静态站）

---

## 1. 背景与目标

做一个可以托管到 GitHub Pages 的**油价查看器**：

- 按**标号**（92 / 95 / 98 / 0 号）展示**当前油价**与**最近一次调价幅度**
- 展示**近 1 周 / 1 月 / 1 年**的油价变化**曲线**
- **页面上可筛选**：省份（全国均价 + 31 省）、标号（多选）、时间区间
- 界面**美观简约**、**移动端 H5 友好**（375px 宽不破版、触摸友好）
- **数据源稳定**：上游抖动/挂掉时页面不能白屏

用户已确认：接受"全国均价 + 31 省可切换 + 页面筛选"方案；`gh` 由执行方自行安装并完成部署调试。

---

## 2. 目标 / 非目标 / 反目标

**目标**

1. 首屏 ≤ 2s 显示当前价（当前省 + 所选标号）。
2. 三档时间区间的曲线 + 调价点标记 + 可交互 tooltip。
3. 上游抖动或 CI 停摆时，页面回退到**最后一次成功快照**并显式标注数据时间。
4. 零运行时依赖：静态 HTML/CSS/JS，无构建步骤、无 CDN、无图表库。

**非目标**

- 城市级油价（需爬小熊油耗城市页，无 CORS、结构易变，稳定性不达标）——见 §12。
- WTI 日线序列（上游 `JO_92272` 只有 Brent，见 §15.7）。
- 每吨幅度折算成元/升（需要密度假设，见 §15.8）。
- 支付/账号/后端服务。
- 加油站成交价（只做发改委挂牌口径）。

**反目标（做出来就算失败）**

- 移动端横向滚动、文字挤压重叠、深色模式不可读。
- 上游一抖动就白屏 / 只报"暂无数据"却拿不出快照。
- 每次访问都硬拉 875KB 上游大表。
- 依赖第三方 CDN 拉图表库，CDN 挂了整站不可用。

## 4. 方案对比（数据层）

| 方案 | 做法 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| **A. 纯浏览器直连上游** | 页面直接 fetch `all_price_by_year` | 无 CI、无仓库数据、永远最新 | 每次访问拉 875KB 且无缓存（C10/C11）；上游间歇 405 时全靠运气；无历史沉淀，"近一年"窗口会随上游滚动左移 | ❌ 作为唯一方案不可行 |
| **B. 浏览器直连第三方聚合 API** | 找一个 `ACAO: *` 的油价 API | 前端最简单 | 实测 `oioweb`(404)、`vvhan`/`pearktrue`(DNS 不解析)、`tanshuapi`(无 CORS)、`apihubs`(油价路由不存在)、`mxnzp`(需 key) → **无一可用** | ❌ |
| **C. 仅 GitHub Actions 快照** | CI 抓取 → 提交 JSON → Pages 同源读 | 同源零 CORS 风险；上游挂了页面照常有数据；可沉淀历史 | 数据有延迟（≤ 抓取周期）；CI 停摆则数据变旧 | ✅ 采用（作为基座） |
| **D. C + 浏览器实时补齐**（**最终方案**） | 快照首屏；仅当快照过期或用户手动刷新时，浏览器再直连上游（可重试），成功则热替换 | 首屏快（~90KB 同源）；数据通常很新；上游或 CI 任一挂掉都能出图；"实时"诉求得到满足 | 实时拉取成本高（875KB/次），需严格限频 | ✅ **采用** |
| E. 自建 Serverless 代理 | Cloudflare Worker 转发 | 实时 | 多一个需运维、可能挂的组件，违背"稳定"诉求 | ❌ |

**最终数据流 = D**：*快照先出图 → 按需实时补齐 → 失败回落快照并标注时间*。

## 5. 系统架构

```
┌─ GitHub Actions (ubuntu-latest, cron 每 2 小时) ────────────┐
│  scripts/fetch-oil-prices.mjs   (Node 20+, 零依赖)           │
│    ├→ cngold all_price_by_year  → 31省×47窗口价格（C1）     │
│    ├→ cngold near_time          → 上次/下次窗口 + 每吨幅度  │
│    ├→ jijinhao kDataList        → Brent 日 K（C5）           │
│    └→ tencent qt.gtimg.cn (GBK) → WTI/Brent 现价快照（C4）   │
│         ↓ 转换 + 校验 + **与历史合并**                       │
│  data/oil-prices.json  →  git commit  →  git push            │
└──────────────────────────────────────────────────────────────┘
                    │ (Pages 静态托管，同源)
                    ▼
┌─ 浏览器 ────────────────────────────────────────────────────┐
│  ① fetch('data/oil-prices.json')  ← 同源，首屏必成功        │
│  ② 若快照 >6h 或用户点刷新 → fetch 上游（重试 2 次）        │
│     成功 → 热替换 + 标注"已更新"  失败 → 保留快照 + 提示     │
│  ③ near_time / 腾讯原油 → 实时补齐"下次调价"与原油现价      │
└──────────────────────────────────────────────────────────────┘
```

**刷新策略（关键取舍）**

- 首屏只拉同源快照（目标 gzip ≤ 30KB），**不**在首屏路径拉 875KB。
- 实时拉取触发条件：**快照 `generatedAt` 早于 6 小时** 或 **用户点「刷新」**。
  - CI 正常时快照总是 < 2h 新 → 绝大多数访客不会触发大流量。
  - CI 停摆（如 §15.10 的 schedule 失效）→ 页面靠实时拉取**自愈**。
- 实时拉取失败：保留快照 + 顶栏提示"数据源暂不可用，当前显示 X 前的快照"，**不白屏**。

## 6. 数据契约：`data/oil-prices.json`

```jsonc
{
  "meta": {
    "generatedAt": "2026-11-26T08:20:11+08:00",   // 快照生成时间（页面据此判新鲜度）
    "schemaVersion": 2,
    "sources": [
      { "name": "金投网 cngold 城市油价", "url": "https://quote.cngold.org/oil/youjia.html" },
      { "name": "金投网 jijinhao 行情",   "url": "https://quote.cngold.org/" },
      { "name": "腾讯财经 外盘期货",       "url": "https://qt.gtimg.cn/q=hf_CL,hf_OIL" }
    ],
    "lastWindow": { "date": "2026-11-13" },
    "nextWindow": { "date": "2026-11-27", "gasolineChange": -440, "dieselChange": -425 },
    "crude": { "wti": 84.13, "brent": 90.87, "wtiChange": 0.54, "brentChange": 0.25, "time": "2026-11-26 16:20" },
    "notes": { "priceBasis": "发改委挂牌价（生效日口径），非加油站成交价" }
  },

  "dates": ["2025-01-03", "2026-11-13"],       // 调价窗口日期轴（升序）；随 CI 累积增长

  "national": {                                 // 全国参考均价（31省算术平均，构建时算好）
    "p92": [7.46], "p95": [7.94], "p98": [9.44], "p0": [7.13], "p89": [6.96],
    "lastAdjust": { "date": "2026-11-13", "p92": -0.52, "p95": -0.55, "p98": -0.55, "p0": -0.54 }
  },

  "regions": {
    "北京市": {
      "regionId": 2,
      "p92": [8.61], "p95": [9.17], "p98": [10.67], "p0": [8.36], "p89": null,
      "lastAdjust": { "date": "2026-11-13", "p92": -0.52, "p95": -0.55, "p98": -0.55, "p0": -0.54 }
    }
    // …共 31 省；n89 等无值标号写 null
  },

  "crudeDaily": { "brent": [["2026-01-02", 90.71]] }   // 仅保留近 400 天，控制体积
}
```

**设计决策**

- **只存价格，不存 `*Change`**：涨跌由相邻窗口相减得出（C7 证明两者一致），体积减半；"最近一次真实调价"在**构建时**算好存 `lastAdjust`。
- **`dates` 单数组**：各省窗口日期一致（C6）→ 各省只存价格数组，长度必须等于 `dates.length`（构建期强校验）。
- **哨兵归一**：`n89/n10/n20/n35` 的 `0` 与 `null` 一律转 `null`（C9）；`p89` 为 null 的省份不参与全国 89 号均价。
- **累积历史**：CI 每次把上游新窗口**合并进**既有 `dates`（按日期去重取并集），上游滚动窗口左移也不丢历史 → "近一年"永远拿得到（§15.5）。
- **全国均价**在构建时算好，前端不做聚合 → 首屏只做一次 JSON 解析 + 数组切片。
- **体积预算**：31 省 × 5 标号 × 47 点 ≈ 7,285 个数字 + 全国 235 + Brent 800 ≈ JSON ≈ 90 KB（gzip ≈ 25 KB）；随历史累积一年后 ≈ 150 KB（gzip ≈ 35 KB）。

## 7. 抓取脚本设计（`scripts/fetch-oil-prices.mjs`）

- **运行时**：Node 20+ 内置模块（`fetch` / `TextDecoder`），**零第三方依赖**（Actions 环境不装包）。
- **模块拆分**：`scripts/lib/transform.mjs`（纯函数：`mergeHistory` / `sentinelToNull` / `computeDeltas` / `findLastAdjust` / `nationalAverage` / `alignSeries` / `sliceBrude` / `buildSnapshot`）+ `scripts/fetch-oil-prices.mjs`（I/O 编排）。纯函数全部可单测。
- **编码处理**：腾讯行情用 `new TextDecoder('gbk').decode(await res.arrayBuffer())`；数字字段全是 ASCII，中文名硬编码映射（`hf_CL`→纽约原油 / `hf_OIL`→布伦特原油）。
- **抓取健壮性**：
  - 每次请求 **重试 2 次**（间隔 1s / 3s），405 与超时都算失败重试（C1 的间歇性 405；另观察到代理偶发截断 ~490KB，须靠重试 + 完整长度校验兜住）。
  - 校验 `Content-Length` 与实际字节一致、JSON 可 `JSON.parse`、`returnCode === 0`、行数 ≥ 1457 级别（C6）。
  - 任一校验不过 → **不写文件**，让 Action 步骤失败（可告警），保留旧快照。
- **失败保护（fail-safe，不覆盖好数据）**：以下任一命中 → 不提交
  1. 上游最新窗口日期 **早于**既有快照的最新日期（上游回退）
  2. 上游窗口数 < 12（历史断裂）
  3. 各省数组长度与 `dates.length` 不一致
- **原子写**：写临时文件再 `rename`，避免 Actions 中断产生半截 JSON。
- **首次播种**：若仓库无快照，用上游当前 47 个窗口初始化。

## 8. CI 工作流（`.github/workflows/deploy.yml`）

- **触发**：`schedule` cron `20 */2 * * *`（UTC → 北京 00:20 / 02:20 / … / 22:20）+ `workflow_dispatch` + `push` 到 `main`。
  - 调价生效时间为当日 24:00（即次日 0 点），**凌晨 02:20 那轮能抓到新价**。
  - 每 2 小时一次；stale 阈值定 **6 小时**（容忍连续 3 次抓取失败）。
- **权限**：`contents: write`（提交数据）、`pages: write`、`id-token: write`。
- **步骤**：checkout → setup-node(20) → 跑抓取脚本 → `git add data` → 有变更才 commit/push → configure-pages → upload-pages-artifact（路径 = 仓库根）→ deploy-pages。
- **部署形态**：静态站（`index.html` + `assets/` + `data/`），无构建；`data/` 随 artifact 发布，页面同源读取。
- **并发**：`concurrency: {group: pages, cancel-in-progress: false}`，避免两个部署互相覆盖。
- **schedule 停摆兜底**：公开仓库 60 天无活动会静默停用 `schedule`（§15.10）→ 页面靠浏览器实时补齐自愈；README 提供本地 keepalive 脚本（每周 `gh workflow run`）。

## 9. 前端设计

### 9.1 信息架构（移动优先，自上而下）

1. **顶栏**：站名「油价看板」· 数据时间戳 · 数据源角标 · 深浅色切换
2. **当前价卡片**（4 张：92 / 95 / 98 / 0）：大号数字（元/升）+ 涨跌额徽标（**涨红跌绿**，国内习惯）+ "最近调价 11-13"
3. **筛选区**：
   - 省份 `<select>`（全国均价 + 31 省）+ 「定位我的省份」按钮（**点击才**调 `ipinfo.io/json`，ACAO:*；不自动调，第三方调用须显式触发）
   - 标号 chips（多选，决定图表同时显示哪几条线；默认 92）
   - 区间 segmented control（近 1 周 / 近 1 月 / 近 1 年）
4. **主图**：自绘 SVG（见 §9.2）
5. **辅助卡片**：下次调价窗口（日期 + 每吨幅度）· 国际原油 WTI/Brent 现价与涨跌 · 上次调价摘要
6. **页脚**：数据源与口径说明（阶梯价、非成交价）· 免责声明 · "数据由 GitHub Actions 定时抓取"

### 9.2 图表（自绘 SVG，零依赖）

- **阶梯线**（step-after）：国内零售价在调价日跳变、期间保持不变，用阶梯线才是**诚实**的画法（直线插值会造出不存在的中间价）。
- **调价点标记**：圆点 + 竖向虚线；tooltip 显示日期、各标号价格、涨跌幅。
- **叠加 Brent 日线**：走**右轴**、低饱和描边，可用开关关闭（WTI 无日线数据，只有现价）。
- **近 1 周视图**：国内价通常**无调价点**（调价周期约 10 个工作日）→ 显式展示"本区间无调价，当前价自 11-13 起未变"的状态文案 + Brent 日线作为区间内唯一波动信号。**不隐藏该档位**（用户明确要求）。
- **交互**：hover / 触摸拖动 → 十字线 + tooltip；点击图例切换标号；区间切换即重算 X 轴窗口。
- **响应式**：`viewBox` + `ResizeObserver` 重算；375px 下仍显示 Y 轴刻度，X 轴标签按区间自适应密度（1 周：每天；1 月：每 3-5 天；1 年：每 1-2 月）。
- **X 轴**用真实日期刻度；由于窗口稀疏，1 年视图的每个窗口都是明确的数据点。

### 9.3 视觉与主题

- 现代简约：中性灰底 + 单一强调色系；卡片圆角 12-16px；数字用 `font-variant-numeric: tabular-nums` 避免跳动。
- 深色模式：`prefers-color-scheme` 自动跟随 + 手动切换（记忆到 `localStorage`）。
- 涨红跌绿配色同时满足对比度要求；**不单靠颜色**传达涨跌（带 ↑/↓ 符号与文字）。
- 动效克制，遵循 `prefers-reduced-motion`。

### 9.4 健壮性

- 快照 JSON 加载失败 → 明确错误态 + 重试按钮，**不白屏**。
- 快照 `generatedAt` 早于 6h → 顶栏"数据可能滞后"提示，并自动尝试一次实时补齐。
- 实时补齐失败 → 保留快照 + 提示"数据源暂不可用，当前显示 X 前的快照"。
- 上游返回被截断（JSON.parse 失败）→ 重试，仍失败则保留快照。

### 9.5 无障碍

- 图表容器 `role="img"` + 动态 `aria-label`（"2025-01-03 至 2026-11-13，92 号汽油 8.37 元/升，较上次调价下跌 0.52 元/升"）。
- 所有交互控件可键盘操作，焦点环可见。
- 筛选区用原生 `<select>` / `<button>`，不搞 ARIA 炫技。

## 10. 数据口径与已知坑

| 坑 | 处理口径 |
|---|---|
| 上游对"不调价"窗口也写一行且涨跌全 0（C8，最近一年有 8 次） | **当前价** = 最新窗口价格；**最近调价幅度** = 最近一次价格**发生变化**的窗口（构建时算 `lastAdjust`），不是"最新窗口的 change" |
| 调价日口径 | cngold 用**生效日**；发改委公告日 = 生效日 − 1 天。全站统一用**生效日**（下次调价显示 11-27） |
| 国内价是阶梯状（~10 个工作日一次） | 阶梯线 + 明确文案；1 周视图叠加 Brent 日线提供日内波动视角 |
| 全国均价无官方口径 | 31 省算术平均，标注为"**全国参考均价**"，与实际零售价可能有差异 |
| 89 号汽油仅 24 个省有值（C9） | 默认不展示，标号筛选中可开启；无值省份显示 `—`，全国均价按有值省份平均 |
| 小众柴油标号（-10/-20/-35）`null` 与 `0` 混用 | 统一归一为 `null`；默认不进 UI |
| 腾讯行情是 GBK | `TextDecoder('gbk')`，中文名硬编码 |
| 上游间歇 405 / 代理偶发截断 | 重试 2 次 + 长度/解析校验；失败保留旧快照 |
| 每吨幅度不折算元/升 | 只显示上游给的元/吨（§15.8） |

## 11. 未决事项与我的判断

| 事项 | 判断 | 理由 |
|---|---|---|
| 仓库可见性 | **public** | GitHub Pages 免费版仅公开仓库可用；仓库内无任何密钥，数据与脚本可公开 |

| schedule 停摆 | 浏览器实时补齐自愈 + README 提供本地 keepalive 脚本 | 公开仓库 60 天无活动会停用 schedule |

## 13. 验收标准

1. 打开页面 2s 内看到当前价与 4 个标号卡片（来自同源快照）。
2. 切换省份 / 标号 / 区间，图表与卡片即时联动，无刷新。
3. 近 1 年视图 ≥ 12 个调价点；曲线为阶梯形；tooltip 数值与 JSON 一致。
4. 下次调价窗口显示 11-27 与每吨幅度；原油现价可实时刷新。
5. 上游 405 / 抓取失败：不产生提交，页面仍显示旧快照并标注时间。
6. 375px 宽无横向滚动、无元素重叠；深浅色均达可读对比度。
7. Actions 定时运行 → 数据提交 → Pages 自动部署 → 线上可访问。

## 15. Builder-check 复核结论（v2 修订依据）

复核发现的 10 个问题，逐条处置：

| # | 问题 | 处置 |
|---|---|---|
| 1 | **C1 不成立**：主表带 ACAO:*、免 Referer，浏览器可直连；架构是否要改 | **架构改为 D（快照 + 实时补齐）**（§4/§5）。同时纠正我原先"405 = 缺 Referer"的误判——那次是**间歇性 405**，不是 Referer 策略 |
| 2 | IP 判省该放 CI 还是浏览器 | 放**浏览器**且**显式触发**（§9.1）；CI runner 在美国，判的是 runner 不是访客 |
| 3 | 哪个 GitHub 账号托管、Pages 域名 | **待用户确认**（唯一需要人回答的事项） |
| 4 | 近 1 周国内曲线是平的 | 保留该档位 + 显式"本区间无调价"状态 + Brent 日线作为唯一波动信号（§9.2） |
| 5 | 上游是滚动 47 窗口，历史会左移 | CI **累积合并**历史，`dates` 单调增长（§6） |
| 6 | 2 小时还是 6 小时 | **每 2 小时**（cron `20 */2 * * *`），stale 阈值 **6h**（§8）；修正 v1 里 §5 与 §8 不一致的 cron |
| 7 | 要不要 WTI 日线 | **不要**：`JO_92272` 只有 Brent；WTI 仅用腾讯现价快照（§9.2） |
| 8 | 每吨要不要折算元/升 | **不折算**：折算需密度假设，会产出用户误读为官方口径的数字；只显示元/吨（§10） |
| 9 | CN 访问 `*.github.io` 不稳 | 接受（用户指定 GitHub Pages），README 注明（§11） |
| 10 | 公开仓库 60 天无活动停用 schedule | 页面靠实时补齐自愈 + README 提供本地 keepalive（§8/§11） |
| 附带 | 代理偶发截断 ~490KB | 抓取脚本**重试 + 长度校验**（§7） |

另外据复核补入的实测事实：`n89`/小众柴油标号的 `0` 与 `null` 哨兵混用（C9）、主表无缓存头（C10）、无更小的当前价端点（C11）、价格差值与 `*Change` 完全一致（C7）。
